# Float — Beauty Workspace Marketplace 💗

Float is a responsive front-end marketplace prototype designed to connect independent beauty professionals with flexible workspace rentals.

The application allows users to explore beauty workspaces, search by location, filter by specialty, view listing details, and simulate a reservation.

## Project Overview

Float was created to make finding professional beauty workspaces more accessible and convenient for independent beauty entrepreneurs.

The concept focuses on connecting makeup artists, hairstylists, lash technicians, nail technicians, and other beauty professionals with rentable salon suites and studio spaces without requiring long-term rental commitments.

This project was developed as part of a multiphase web development portfolio assignment.

## Features

- Responsive homepage
- Beauty workspace listings
- Location-based search
- Specialty filters
- Workspace descriptions and amenities
- Daily rental pricing
- Interactive favorite buttons
- Date selection
- Simulated booking confirmation
- Mobile-friendly design

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or your preferred browser.
4. Explore the listings and test the interactive features.

No additional JavaScript libraries or backend installation is required.

## JavaScript Functionality

JavaScript handles the application's interactive features, including:

- Dynamically rendering workspace listings
- Filtering results by location and specialty
- Updating favorites
- Displaying workspace information
- Handling reservation date selection
- Generating simulated booking confirmations

The application uses event listeners, arrays, functions, and DOM manipulation to create an interactive user experience.

## UI/UX Design

Float's interface was inspired by the original Figma wireframes and high-fidelity mobile mockups.

The visual design uses soft pink tones, coral accents, rounded cards, modern typography, and responsive layouts to create a clean and professional beauty-focused experience.

## Project Limitations

Float is currently a front-end prototype and does not include:

- Real user authentication
- Database integration
- Live workspace availability
- Payment processing
- Permanent booking records
- Professional license verification

All workspace listings, prices, and booking confirmations are fictional and used for demonstration purposes.
